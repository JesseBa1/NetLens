关于

NetLens 离线版：所有解析都在本机浏览器完成，不联网、不上传数据。
去重说明：pktmon 会在多个驱动组件重复记录同一个包，NetLens 按「五元组 + 序号 + 载荷指纹 + 3ms 窗口」去重。
统计单位为 IP 包字节（不含以太网帧头）；「载荷」为去掉 TCP/IP 头与纯 ACK 后的应用层字节。
