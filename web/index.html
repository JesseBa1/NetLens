三步用起来

1
抓包 —— 双击 NetLens.cmd，UAC 点"是"，等 3 分钟（这期间正常上网）。 不用装 Wireshark，用的是 Windows 自带的 pktmon。
2
看结论 —— 结果页顶部的横幅会直接告诉你"有没有发现异常上传"。 绿色=没发现；黄色=出现了值得注意的特征，点"异常判定"看详情。
3
看细节 —— "进程"页看哪个程序传得多，"连接明细"页看每一条连接。 可以把结果导出成 Markdown / CSV 存档。

这些数字是什么意思

  • 上行 / 下行：这台电脑发出的 / 收到的数据量。家庭宽带通常下行远大于上行。
  • 应用层上行：去掉 TCP 确认包和协议头之后，真正的"内容上传"。判断偷传要看这个。
  • 远端 IP：你连过去的服务器地址；"域名"列是它的名字（能解析出来才有）。
  • 上行峰值：1 秒内最高上传速度。PCDN 偷跑往往长时间维持在几 Mbps 以上。

什么情况算"不正常"

  • 你没在传文件、没开直播，但上行长期 > 2 Mbps；
  • 某个陌生进程向几十个陌生 IP 同时上传（PCDN 的典型特征）；
  • 有公网 IP 主动连进来（说明有服务暴露在公网，或被扫描）；
  • 上行远大于下行，且持续存在。

常见问题

  • 提示"拒绝访问"：没有管理员权限。请从 NetLens.cmd 启动并允许 UAC；只分析文件则不需要。
  • 抓到的流量很小：这 3 分钟电脑基本空闲，正常。可以在你怀疑的场景下再抓一次。
  • 看不到具体网站：HTTPS 是加密的，走了代理（如 Clash）就更看不到；只能看到代理节点 IP。要看站点需要代理软件自己的连接日志。
  • 能不能抓别人的电脑：不能，只抓本机。
  • 数据会不会被上传：不会。解析全在本机浏览器里完成，工具不联网。

关于

NetLens 离线版：所有解析都在本机浏览器完成，不联网、不上传数据。
去重说明：pktmon 会在多个驱动组件重复记录同一个包，NetLens 按「五元组 + 序号 + 载荷指纹 + 3ms 窗口」去重。
统计单位为 IP 包字节（不含以太网帧头）；「载荷」为去掉 TCP/IP 头与纯 ACK 后的应用层字节。
